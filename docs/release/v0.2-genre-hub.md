# v0.2-genre-hub (2026.11.22)

AMU의 첫 번째 장르 허브 버전.
단일 클리커 게임에서, 로비와 포탈을 통해 여러 장르 레벨을 오가며 공용 재화로 새 장르를 해금하는 허브 구조로 전환함.

## 하이라이트

- **장르 허브**: Lobby에서 포탈을 통해 Clicker / Defense 레벨로 이동
- **공용 재화 루프**: Defense 매치 결과 정산 → 공용 재화 획득 → Lobby에서 해금 확인 → 새 레벨 해금
- **신규 장르 Defense**: 그리드 BFS 경로 탐색, 경로를 막는 타워 배치 거부, 웨이브 · 라이프 · 승패 판정, 결과 화면
- **통합 세이브**: 공용 재화 · 해금 진행도 + GameplayTag 키 기반 레벨별 스냅샷
- **모듈 구조**: HubCore + Lobby / Clicker / Defense, 의존 방향을 Build.cs로 강제
- **프로젝트명 변경**: ClickerGame → AMU

## 이 버전의 플레이 흐름

1. Lobby에서 시작, 공용 재화가 HUD에 표시됨
2. Defense 포탈로 이동해 매치 진행 (타워 배치 → 웨이브 방어)
3. 승리 / 패배에 따라 공용 재화 정산 후 Lobby로 복귀
4. 잠긴 Clicker 포탈과 상호작용 → 해금 확인 팝업에서 가격과 보유 재화 확인
5. 해금 후 Clicker 레벨 진입, 클릭 · 업그레이드 · 오프라인 보상

## 구조 변경 요약

| 영역 | v0.1 | v0.2 |
|---|---|---|
| 게임 구성 | Clicker 단일 레벨 | Lobby + Clicker + Defense |
| 재화 | Clicker 재화 | Clicker 재화 + 공용 재화 |
| 서브시스템 | GameInstance 중심 | 공용은 GameInstance, 레벨 전용은 GameMode 기준 World Subsystem |
| 세이브 | Clicker 스냅샷 | 공용 데이터 + GameplayTag 키 레벨 스냅샷 (`FInstancedStruct`) |
| 코드 구조 | 단일 모듈 `ClickerGame` | `HubCore` + `Lobby` / `Clicker` / `Defense` |
